# MathVizor — готовый сайт проекта

Это окончательная версия статического сайта по статье-заявке на номинацию
«Лучшая онлайн-разработка» в области математики и математического образования.
Демо-версия исключена: все страницы и разделы — постоянные, рабочие.

## Где найти сайт

**Папка с сайтом:**

```
C:\Users\HOME\Desktop\компьютерные сети\mathvizor-site\
```

**Главный файл:**

```
C:\Users\HOME\Desktop\компьютерные сети\mathvizor-site\index.html
```

Как открыть: зайдите в папку `mathvizor-site` через Проводник и дважды щёлкните
по `index.html`. Сайт откроется в браузере. Сервер, интернет и сборщики не нужны —
все стили, скрипты и картинки лежат рядом в этой же папке.

Прямой адрес в браузере:

```
file:///C:/Users/HOME/Desktop/компьютерные сети/mathvizor-site/index.html
```

## Страницы сайта

| Файл | Страница | Что на ней |
|---|---|---|
| `index.html` | Главная | Название проекта, ключевые цифры, преимущества, цикл обучения, ссылки на платформу и статью |
| `platform.html` | Платформа | Цикл исследования, рабочий лист, четыре модуля, таблица соответствия компонентов педагогическим задачам, галерея фотографий |
| `technology.html` | Архитектура | Трёхслойная архитектура: TypeScript/React, Python/FastAPI/SymPy, PostgreSQL, LTI 1.3, xAPI |
| `tasks.html` | Задания | Четыре типа заданий, три уровня обратной связи, пример с функцией `f(x)=x³+ax` |
| `pedagogy.html` | Педагогика | Концепция «видимого мышления», таксономия целей, сравнение с электронным учебником, анализ аналогов |
| `methodology.html` | Методика | Четыре этапа исследовательского цикла и фрагмент урока по производной |
| `results.html` | Результаты | Диагностика 86 обучающихся, динамика 54→78 % и 53→64 %, таблица показателей, опрос |
| `about.html` | О проекте | Авторы, университет, новизна, область применения, контакты |
| `publications.html` | Публикации | Аннотации на русском и английском, статья PDF, список литературы |
| `404.html` | Ошибка | Страница для несуществующих адресов |

Навигация: `Главная`, `Платформа` (Платформа / Архитектура / Задания),
`Педагогика` (Педагогический дизайн / Методика / Результаты), `О проекте`.
Постоянная кнопка в шапке — «Читать статью».

```
    ├── js/main.js          — мобильное меню

```
