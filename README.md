# MathVizor — готовый сайт проекта

Это окончательная версия статического сайта по статье-заявке на номинацию
«Лучшая онлайн-разработка» в области математики и математического образования.
Демо-версия исключена: все страницы и разделы — постоянные, рабочие.

## Где найти сайт

**Папка с сайтом:**

```
D:\сайт\mathvizor-site\
```

**Главный файл:**

```
D:\сайт\mathvizor-site\index.html
```

Как открыть: зайдите в папку `mathvizor-site` через Проводник и дважды щёлкните
по `index.html`. Сайт откроется в браузере. Сервер, интернет и сборщики не нужны —
все стили, скрипты и картинки лежат рядом в этой же папке.

Прямой адрес в браузере:

```
file:///D:/сайт/mathvizor-site/index.html
```

**Рабочий адрес опубликованного сайта:**

```
https://asmankinigor.github.io/mysite/
```

Ссылка добавлена на главную страницу (кнопка «Открыть сайт проекта») и в раздел
«Контакты». Адрес из статьи `https://mathvizor.example.org` был демонстрационным
и в сайт не переносится.

## Как работает ввод задачи

Форма на `tasks.html#recognizer` содержит только одно поле — **формулу функции**.
Словесное описание, выбор «что видно на графике» и загрузка изображения графика
удалены. Переменные задаются буквами в скобках: `f(x)`, `f(t)`, `f(x,y)`; остальные
буквы считаются параметрами. Поддерживаются также записи производной `f'(x)`,
`f′(t)` и `df/dx`.

Кнопка «Распознать и построить методику» запускает анализ в браузере
(`assets/js/main.js`). Тип задания определяется только по формуле:

- запись производной — «Объяснение»;
- несколько переменных — «Исследовательские»;
- наличие параметра — «Построение модели»;
- формула одной переменной без параметров — «Распознавание структуры».

Тип можно изменить вручную — методика пересчитается для той же формулы.

После этого **генерируется методика именно под введённый пример**, а не общий текст:

- в шагах используется ваша формула и найденные по ней характеристики;
- формула разбирается в AST (рекурсивный спуск): поддерживаются `+ − * / ^`, скобки,
  неявное умножение (`2x`, `ax`, `2sin(x)`), константы `pi` и `e`, параметры `a, b, k`
  и элементарные функции `sin`, `cos`, `tan`, `cot`, `sqrt`/`root`, `exp`, `ln`, `lg`,
  `abs`, `arcsin`, `arccos`, `arctan` (для `tanh`/`cosh` тоже есть правила);
- символьно находятся производная или частные производные, численно анализируются
  знак, интервалы монотонности, экстремумы или критические точки; шаги 3 и 4 содержат
  конкретные интервалы, точки и значения;
- для одной переменной строится SVG-график с осями, стрелками, началом координат `O`,
  подписями переменной и функции, сеткой с масштабом, легендой и точками экстремумов;
- для двух и более переменных строится карта уровней по первым двум переменным,
  остальные переменные фиксируются нулями;
- координаты показываются только при наведении на линию графика или контур уровня;
  наведение на пустую область плоскости подсказку скрывает;
- график можно перемещать перетаскиванием и масштабировать колесом мыши — это
  позволяет анализировать функцию за пределами исходного окна;
- если формула не распознана, сайт честно сообщает об этом и просит уточнить запись.

Для примера `f(x) = x³ + a*x` генерируется: `f′(x) = 3 · x² + a`, интервалы знака и
максимум/минимум при `a = −3` (`x = ±1`, `f = ±2`), отсутствие экстремумов при `a = 0`
и `a = 3`, три графика с подписанным масштабом. Для `f(t) = sin(t)` все подписи и
выводы используют `t`; для `f(x,y) = x^2 + y^2` находится минимум в `(0; 0)` и строится
карта уровней.

Всё реализовано на чистом JavaScript: сервер, API и внешние библиотеки не нужны,
сайт работает через `file://`.
